# 노션 페이지 공유 확인 요청

`spec-to-datasheet`(정규 업데이트 기획 문서 → 밸런스 시트 입력용 정리 이슈 초안 생성)가
노션 API로 기획 문서 페이지를 읽으려면, 그 페이지가 이 자동화용 integration에
**Connections로 공유**돼 있어야 합니다.

**확인해 주실 것**: 정규 업데이트 기획 문서가 있는 노션 페이지(들)를 열어서, 우측 상단
`···` → `Connections`에 이 자동화용 integration이 추가돼 있는지 봐 주세요. 없으면 추가만
해주시면 됩니다 — 별도 권한 승인은 아니고, 페이지 소유자가 할 수 있는 공유 설정입니다.

**왜 필요한가**: 지금은 이 자동화 환경에 `NOTION_TOKEN` 자체가 없어서, integration이
실제로 어느 페이지에 공유돼 있는지 확인이 안 됩니다. 이게 확인돼야 `spec-to-datasheet`
착수가 가능합니다 — 이 문서에 적힌 정보(기획 내용)를 읽어서 밸런스 시트에 뭘 입력해야
할지 정리하는 게 이 스킬의 역할이기 때문입니다.
