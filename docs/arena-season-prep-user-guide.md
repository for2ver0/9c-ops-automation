# 아레나 시즌 준비 — 사용 설명서 (담당자용)

> 이 문서는 개발자가 아니라 **아레나 시즌을 준비하는 담당자**를 위한 것입니다. 명령어·코드는
> 하나도 없습니다 — Claude에게 **말로** 요청하면, Claude가 알아서 필요한 걸 실행하고 결과를
> 사람 말로 정리해서 알려줍니다.

## 기본 원칙

- **말로만 하면 됩니다.** "이번 시즌 상금 표 만들어줘"처럼 편하게 요청하세요.
- **모르는 값은 모른다고 하면 됩니다.** Claude가 지난 시즌 값이나 관측된 기준값을 제안합니다.
- **Claude가 등록·게시·서명을 대신 하지 않습니다.** 이 세 가지는 항상 담당자가 직접 합니다 —
  Claude는 그 직전까지 계산·확인만 하고, "이제 등록해주세요" / "이제 올려주세요" / "서명해주세요"
  라고 요청합니다.
- **문제가 있으면 Claude가 멈추고 알려줍니다.** "치명적인 문제"가 있으면 다음 단계로 넘어가지
  않고, 무엇을 어디서 고쳐야 하는지 설명합니다.

---

## 상황별로 이렇게 말씀하시면 됩니다

| 하고 싶은 일 | 이렇게 말씀하세요 (예시) |
| --- | --- |
| 상금 표 만들기 | "이번 시즌 상금 표 만들어줘. 풀은 40만이고 배수는 지난번이랑 똑같이 해줘" |
| 지금 등록된 시즌들 확인 | "지금 오딘·헤임달에 등록된 시즌 뭐 있어?" |
| 새 시즌 값이 등록해도 괜찮은지 확인 | "이번 시즌 이렇게 등록하려는데 확인해줘: [네트워크, 시즌 번호, 타입, 시작일, 라운드 수 등]" |
| 공지 초안 요청 | "이번 시즌 공지 초안 만들어줘" |
| 시즌 진행 중 상태 확인 | "지금 상태 어때?" / "캐시 문제없어?" |
| 정산 후 거래 확인 | "이 트랜잭션 성공했는지 확인해줘: (txId 붙여넣기)" |
| 지금까지 진행 상황 전체 요약 | "지금까지 확인한 거 전부 정리해서 보여줘" |
| 막혔을 때 | "왜 안 돼?" / "이거 어떻게 고쳐?" — Claude가 원인과 백오피스에서 고칠 위치를 설명합니다 |

## 전체 흐름 (한눈에)

1. **상금 내용을 말씀해주세요** — 총 풀, (있으면) 배분 비율·배수. 모르면 "지난 시즌이랑 똑같이"라고
   하셔도 됩니다.
2. Claude가 **상금 표(이미지)**를 만들어 보여줍니다. 확인해주세요.
3. 새 시즌이면 Claude가 **등록 전 확인**을 해드립니다. 문제없으면 알려주는 값 그대로 백오피스에
   담당자가 직접 등록합니다.
4. 등록이 끝났다고 말씀해주시면, Claude가 **공지 초안**을 만들어 보여줍니다. 다듬어서 직접 디스코드에
   올려주세요.
5. 시즌이 진행되는 동안 궁금하면 "지금 상태 어때?"라고 물어보시면 됩니다.
6. 시즌이 끝나면 Claude에게 알려주세요 — **최종 지급 계산**을 해드립니다. 확인 후 직접 NCG 서명·전송.
7. 서명·전송한 뒤 받은 거래 번호(txId)를 알려주시면, **성공했는지 확인**해드립니다.

## 지금 알아두셔야 할 한계

- **정산(4순위) 부분은 아직 완전하지 않습니다.** 거래가 성공했는지는 확인해드릴 수 있지만, "각
  유저가 정확히 계산된 만큼 받았는지"까지는 아직 확인 못 합니다(조사해보니 그걸 대조할 원본
  기록이 시스템에 아예 없다는 게 확인됐습니다). 필요하면 담당자가 별도로 확인해주셔야 합니다.
- **캐시 지연 경고(WARN)는 거의 항상 뜹니다.** 시스템 자체가 상시로 좀 뒤처져 있는 상태라
  그렇습니다 — "치명적(FATAL)" 표시만 진짜 긴급으로 보시면 됩니다.
